
# Handwritten Digit Classifier

## Project Overview
This project identifies handwritten digits (0-9)
using Machine Learning and the K-Nearest Neighbors
(KNN) algorithm.

## Dataset
- Dataset: Scikit-learn Digits Dataset
- Total Images: 1797
- Image Size: 8x8 pixels
- Classes: 0 to 9

## Technologies Used
- Python
- NumPy
- Matplotlib
- Pandas
- Scikit-learn
- Google Colab

## Machine Learning Algorithm
K-Nearest Neighbors (KNN)

## Train-Test Split
- Training Data: 80%
- Testing Data: 20%

## K Value Comparison

| K Value | Accuracy |
|---------|----------|
| 1 | 97.78% |
| 3 | 98.33% |
| 5 | 98.61% |
| 9 | 98.06% |

## Best Model
KNN with K = 5

## Final Accuracy
98.61%

## Conclusion
The model successfully classifies handwritten
digits with 98.61% test accuracy.
